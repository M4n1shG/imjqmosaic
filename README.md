# imJQMosaic (2009)

> ⚠️ **Archived**: This is the original 2009 jQuery plugin, preserved for historical reference.  
> For the modern, zero-dependency version, see **[image-to-mosaic](https://github.com/M4n1shG/image-to-mosaic)**.

A simple jQuery plugin for creating mosaic effects on images.

## History

Originally released in 2009 on Google Code. The platform shut down in 2015, and the automatic GitHub migration failed. This code was recovered from [a gist preserved by @bchumney](https://gist.github.com/bchumney/7061748).

Rebuilt from scratch in 2024 as **image-to-mosaic** — now with 6 patterns, 8 hover effects, animations, drag support, and zero dependencies.
